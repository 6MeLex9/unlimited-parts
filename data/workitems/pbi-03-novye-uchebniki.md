# PBI: Как клиент, я хочу просмотреть новые учебники

- **Тип:** PBI (User Story)
- **Part of:** Feature «Осваиваем дашборды» (#2)
- **Спринт:** Sprint 2 (текущий)
- **Оценка:** 5 SP · **Приоритет:** 2

## User story

> Как клиент, я хочу просмотреть новые учебники, чтобы знакомиться с новыми
> продуктами до покупки.

## Условия приёмки

- [ ] На дашборде есть блок «Новые учебники» (каталоги продукции)
- [ ] Список берётся из таблицы `Product` (`IsActive = 1`)
- [ ] Пустые категории не отображаются
- [ ] Карточка показывает название, цену со скидкой и остаток

## Как проверить на тестовых данных

```sql
SELECT TOP 5 p.Sku, p.Name, p.Price, p.Stock
FROM Product p
WHERE p.IsActive = 1
ORDER BY p.Id DESC;
```

Ожидаемо: 5 строк, среди них `PD-9001 Pedal Platform Alloy` и
`GL-8001 Gloves Gel Short` (последние записи каталога).

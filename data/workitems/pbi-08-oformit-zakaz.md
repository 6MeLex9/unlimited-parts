# PBI: Как клиент, я хочу оформить заказ

- **Тип:** PBI (User Story)
- **Part of:** Feature «Оформление заказа» (#7)
- **Спринт:** Sprint 3 (запланирован)
- **Оценка:** 8 SP · **Приоритет:** 1

## User story

> Как клиент, я хочу оформить заказ из корзины, чтобы получить товары с доставкой.

## Условия приёмки

- [ ] Создаётся запись в `Orders` с `Status = 'Pending'`
- [ ] Позиции переносятся из `Cart` в `OrderItem`
- [ ] `Orders.TotalAmount` = сумма `LineTotal` позиций
- [ ] Корзина очищается после оформления
- [ ] Остаток `Product.Stock` уменьшается на количество

## Проверка на тестовых данных

Клиент `Id = 1` (`user001@unlimitedparts.demo`), корзина `sess-1234`, 2 позиции.
После оформления: новый `OrderNumber` вида `ORD-202410-0121`, корзина пуста.

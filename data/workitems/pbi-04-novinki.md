# PBI: Как клиент, я хочу видеть новинки на главной странице

- **Тип:** PBI (User Story)
- **Part of:** Feature «Осваиваем дашборды» (#2)
- **Спринт:** Sprint 2 (текущий)
- **Оценка:** 3 SP · **Приоритет:** 2

## User story

> Как клиент, я хочу видеть новинки на главной странице, чтобы сразу замечать
> актуальный ассортимент.

## Условия приёмки

- [ ] Главная страница показывает 8 последних активных товаров
- [ ] Для товаров со скидкой (`Discount > 0`) отображается перечёркнутая старая цена
- [ ] Товары без остатка (`Stock = 0`) помечаются «Нет в наличии»

## Проверка на тестовых данных

| Sku | Ожидаемое поведение |
| --- | --- |
| `HL-U509` | старая цена 1211.11 → новая 1090.00 |
| `BK-M18B-48` | бейдж «Нет в наличии» |
| `PD-9001` | обычная карточка без скидки |

# Feature: Оформление заказа

- **Тип:** Feature
- **Part of:** Epic #1 «Обучение продуктам»
- **Спринт:** Sprint 3 (запланирован)
- **Area (label):** `area: PUL-Web`

## Описание

Сквозной сценарий покупки: из корзины (`Cart`) в заказ (`Orders`) с позициями
(`OrderItem`), оплатой и отслеживанием статуса.

## Сценарии (Sub-issues)

| Тип | Сценарий | Оценка |
| --- | --- | --- |
| PBI | Как клиент, я хочу оформить заказ | 8 |
| PBI | Как клиент, я хочу оплатить заказ картой | 5 |
| PBI | Как клиент, я хочу отслеживать статус заказа | 3 |

## Критерии приёмки

- [ ] Заказ создаётся со статусом `Pending`
- [ ] `TotalAmount` равен сумме `OrderItem.LineTotal`
- [ ] Номер заказа в формате `ORD-YYYYMM-0000`

## Тестовые данные

120 заказов и 301 позиция заказа уже есть в `data/sql/02_seed_data.sql` — на них
проверяются статусы `Completed / Shipped / Pending / Cancelled`.

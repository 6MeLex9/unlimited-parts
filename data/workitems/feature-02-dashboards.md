# Feature: Осваиваем дашборды

- **Тип:** Feature
- **Part of:** Epic #1 «Обучение продуктам»
- **Спринт:** Sprint 2 (текущий)
- **Area (label):** `area: PUL-Web`

## Описание

Набор клиентских сценариев, связанных с просмотром дашбордов: витрина новинок,
карточка товара, корзина и учебники (каталоги) по продукции. Именно сюда входит
исходная user story из методички: «Как клиент, я хочу просмотреть новые учебники».

## Сценарии (Sub-issues)

| Тип | Сценарий | Оценка |
| --- | --- | --- |
| PBI | Как клиент, я хочу просмотреть новые учебники | 5 |
| PBI | Как клиент, я хочу видеть новинки на главной странице | 3 |
| PBI | Как клиент, я хочу добавить товар в корзину | 5 |
| Bug | Карточка товара не отображает скидку | 1 |

## Критерии приёмки

- [ ] Все PBI закрыты
- [ ] Дефекты `priority: 1` закрыты или перенесены в Sprint 3 с обоснованием
- [ ] Дашборды работают на тестовом наборе данных

## Замечания по тестовым данным

Для проверки дашбордов используется `OrderItem` + `Product`: скидка задана полем
`Discount` (доля, например `0.10`), её отсутствие в карточке — дефект Bug «Карточка
товара не отображает скидку».

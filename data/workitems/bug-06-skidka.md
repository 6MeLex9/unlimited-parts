# Bug: Карточка товара не отображает скидку

- **Тип:** Bug
- **Part of:** Feature «Осваиваем дашборды» (#2)
- **Спринт:** Sprint 2 (текущий)
- **Severity:** 2 — Critical · **Приоритет:** 1

## Окружение

- Тестовые данные: `data/Product.json`, запись `Id = 15` (`HL-U509`)
- `ListPrice = 1211.11`, `Discount = 0.10`, `Price = 1090.00`

## Шаги воспроизведения

1. Открыть карточку товара `HL-U509`.
2. Посмотреть на блок цены.

## Фактический результат

Показана одна цена `1090.00` без перечёркнутой старой цены и без бейджа скидки —
клиент не видит выгоды.

## Ожидаемый результат

Показаны `1211.11` (перечёркнуто) и `1090.00`, бейдж «−10 %».

## Дополнительно

Поле `Discount` приходит в API как доля (`0.1`), а шаблон ожидает проценты —
проверить конвертацию во view-модели.

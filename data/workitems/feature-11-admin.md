# Feature: Администрирование каталога

- **Тип:** Feature
- **Part of:** Epic #1 «Обучение продуктам»
- **Спринт:** Sprint 1 (завершён)
- **Area (label):** `area: PUL-Web`

## Описание

Управление товарами и категориями без прямых запросов к БД. Именно этот Feature
заменяет ручную подготовку тестовых данных из лабораторной работы.

## Сценарии (Sub-issues)

| Тип | Сценарий | Оценка |
| --- | --- | --- |
| PBI | Как администратор, я хочу добавить товар в каталог | 5 |
| PBI | Как администратор, я хочу скрыть снятый с продажи товар | 2 |
| PBI | Как администратор, я хочу управлять категориями каталога | 3 |

## Критерии приёмки

- [ ] Новый товар получает уникальный `Sku`
- [ ] `Product.Price` пересчитывается из `ListPrice` и `Discount`
- [ ] Скрытый товар (`IsActive = 0`) не попадает в каталог

## Связь с тестовыми данными

Каталог сгенерирован скриптом `tools/generate_seed_data.js`; тот же формат
ожидает и API каталога.
